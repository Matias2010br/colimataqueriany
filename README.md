# Colima Taqueria II — Website Demo

Single-page website concept for **Colima Taqueria II**, a family-owned Mexican taqueria in the Bronx, NY.

Built by **Matias Olivera** — Web Designer.

---

## What's inside

| File | Purpose |
|---|---|
| `index.html` | The entire site — HTML, CSS and JS in one file. No build step, no dependencies. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is. |

---

## Publish it on GitHub Pages (2 minutes)

1. Create a new repository on GitHub (public).
2. Upload `index.html` and `.nojekyll` to the root of the repo.
3. Go to **Settings → Pages**.
4. Under *Build and deployment → Source*, pick **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)` → **Save**.
6. Wait ~1 minute. Your site is live at:
   `https://<your-username>.github.io/<repo-name>/`

To use a custom domain later, add it under **Settings → Pages → Custom domain**.

## Real data used

Everything on the page comes from the restaurant's own public profiles — no placeholder copy, no stock photography.

- **Photos** — the business profile gallery on Google Maps (storefront, dining room, Catrina mural, birria quesa-tacos, street tacos, cocktails).
- **Logo** — the official brand mark, embedded directly in the file as a data URI.
- **Menu & prices** — published on the restaurant's delivery listings.
- **Contact & hours** — Google Business Profile.
- **Reviews** — published reviews on Google Maps and Yelp.

## Features

- **Bilingual EN / ES** — one switch in the header translates the whole page, including reviews and the hours table.
- **Live hours** — today's row highlights automatically from the visitor's date.
- **Motion** — hero parallax, neon flicker, infinite marquee, scroll reveals, animated counters, image zoom on hover.
- **Mobile action bar** — Call / Menu / Directions fixed to the bottom on phones.
- **Responsive** — single-column layout below 980px, mobile nav below 760px.
- **No dependencies** — only Google Fonts (Alfa Slab One, Rye, Space Grotesk) is loaded externally.
